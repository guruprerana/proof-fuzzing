# Complete set of experiments

1. Evaluating the existing tables with Claude Code and one open-source agent
2. Evaluating strongest mutations with Ultra/Max modes of agents
3. Competing different agents against each other, perhaps on two or three datasets. Who is able to break other models?
4. Ablation with length of proof. Are longer proofs easier to break?
5. Reporting average size of mutations, number of lines changed etc.
6. Reporting span of influence of the mutations.
7. Transfer strategies across datasets.
8. Control for proof length: if length is the main driver, a generic agent should break the judge at a similar rate on length-matched proofs.
